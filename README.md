# HR 201 Employee Management & Database System

A comprehensive React + TypeScript web application for HR employee record keeping (201 files), salary history, memo issuance, document tracking, analytics dashboard, and CSV export.

## 🚀 Features

- **201 Employee Management**: Full profile tracking (Personal details, Contact, Job, Employment Status, Government IDs, Emergency Contacts).
- **Custom Department Input**: Pre-populated suggestions and support for custom department titles.
- **Salary History Tracking**: Log salary adjustments, previous/new salaries, dates, reasons, and approvals.
- **Memo Issuance**: Draft, issue, and keep historical records of employee memos and notices.
- **Document Expiry & Status Tracking**: Monitor status and expiry dates for 201 document requirements (NBI, Medical, Contracts, etc.).
- **Printable 201 File Sheet**: Generate clean, professional printable employee profiles with comprehensive history.
- **ID Card Generator**: Instant employee ID preview and printable card generation.
- **CSV Data Import & Export**: Download entire employee masterlists or filter by company/department.

## 🛠️ Local Setup Instructions

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn` / `pnpm` / `bun`

### Installation

1. **Clone the repository:**
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd <YOUR_REPO_NAME>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000` (or the port shown in your terminal).

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
